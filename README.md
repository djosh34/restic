# restic (companion tooling)

Planning repo for the missing pieces around [restic](https://github.com/restic/restic) for a large macOS backup to S3:
a supervising launchd daemon, lock-free read-only browsing, low local disk/RAM use, and a first backup that survives weeks of sleep, wake and interruption.

Planning happens on the issue tracker (see the `wayfinder:map` issue). Research notes live in `docs/research/`.
